## 🏛️ [01] CONTRIBUTION WORKFLOW

To ensure the integrity of the **Oracle-VX** and **Security-Core**, all contributions must follow this strict pipeline:

1. **Fork the Repository:** Create your own sovereign fork of `VX_NETWORK`.
2. **Create a Feature Branch:** Branch out from `main` using a descriptive namespace (`feature/pqc-encryption`, `docs/update-registry`, etc.).
3. **Commit Standards:** Write clear, concise commit messages detailing the architectural or logical impact of your changes.
4. **Submit a Pull Request (PR):** Open a PR against the `main` branch with a comprehensive description of your implementation.
